# Compact-Flood-Resilience-Platform
Innovate 4 Impact Hackathon Codebase

##Project Title: Compact Flood Resilience Platform
##Problem Statement:
Flood disasters often create challenges such as:

-Delayed emergency reporting
-Lack of visual preparedness tools
-Slow victim identification
-Unsafe evacuation routes
-Inefficient volunteer allocation
-Communication issues during disasters

There is a need for a low-cost, scalable, and intelligent flood management platform.


##Our Solution:
The Compact Flood Resilience Platform integrates three lightweight digital tools into a unified command system for flood preparedness and emergency response:

Web-Based AR Flood Simulator
Drone-Based Computer Vision Engine
Smart Command Dashboard

This platform provides citizens, volunteers, and emergency teams with visualization tools, AI-assisted rescue support, and intelligent routing during flood situations.


##Key Features:
-Flood visualization using WebXR
-AI-based victim detection using YOLOv8
-SOS generation and tracking
-Volunteer allocation
-Safe route generation
-Flood zone mapping
-Offline support
-Low-cost serverless deployment


##Expected Impact
Faster disaster response
Better citizen preparedness
Improved volunteer coordination
Reduced response time
Safer evacuation routes
Low-cost deployment
