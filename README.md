# Compact-Flood-Resilience-Platform
Innovate 4 Impact Hackathon Codebase

##Project Title: Compact Flood Resilience Platform
##Problem Statement:
Flood disasters often create challenges such as:

-Delayed emergency reporting
-Lack of visual preparedness tools
-Slow victim identification
-Unsafe evacuation routes
-Inefficient volunteer allocation
-Communication issues during disasters

There is a need for a low-cost, scalable, and intelligent flood management platform.


##Our Solution:


##Key Features:
-Flood visualization using WebXR
-AI-based victim detection using YOLOv8
-SOS generation and tracking
-Volunteer allocation
-Safe route generation
-Flood zone mapping
-Offline support
-Low-cost serverless deployment
